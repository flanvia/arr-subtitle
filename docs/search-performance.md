# 전체 검색 지연 수정 계획

## 원인과 범위

`Working`을 40초 실행한 재현에서 요청 46개를 보냈고 작품 하나만 조사를 마쳤다. 작품별 순차 실행, 같은 제작자 블로그의 반복 조사, 관련 없는 메뉴와 페이지 링크 확장, 진행 출력 부재 및 전체 제한 부재가 원인이다.

같은 블로그는 한 실행에서 한 번 순회하고 관련 작품들에 결과를 배분한다. 작품 메타데이터와 서로 다른 블로그는 최대 4개씩 처리한다. 호스트 요청 간격 및 SSRF 검증은 유지한다. 검색과 카테고리는 먼저 처리하되, 확인하지 않은 과거 게시물을 완전 조사했다고 표시하지 않는다.

전체 검색은 기본 60초이며 `search --timeout <seconds>`로 1초부터 600초까지 지정한다. timeout은 부분 결과와 미완료 출처를 반환하고 종료 코드 1이다. 사용자 취소는 같은 부분 결과를 반환하고 130이다. 검색 진행 및 발견 회차는 stderr로 즉시 전달한다. JSON stdout은 최종 문서 하나만 유지한다.

OpenSSL 배포 방식 변경은 이 성능 수정 범위가 아니다. 잘못된 외부 주소를 임의 교정하거나 인증서 검사를 끄지 않는다.

## 실행

- [x] 공유 블로그 탐색 및 작품별 결과, 진행 콜백과 전체 timeout 구현
- [x] 탐색 URL 정규화와 작품 검색 및 관련 카테고리 우선 처리
- [x] 마지막 대기자가 취소한 HTTP 작업과 대기 요청을 정리
- [x] 중복 순회, 독립 출처 동시 실행, 진행 시점, 취소와 timeout 부분 결과 검증
- [x] 전체 테스트, NativeAOT 및 실제 Working과 흉란영애 검색 비교
- [x] 사용법과 결과 기록 갱신

사용자가 원인 수정 전체를 승인했다. 구현 후 검증을 수행했으며 이후 커밋, push 및 Release도 승인했다. 검색 및 JSON, 누적 합본, 정적 TLS 수정을 함께 `v0.1.1`로 배포한다.

## 리뷰 보완

공유 순회 구현을 별도 리뷰했다. 게시물 시즌이 작품의 명시 시즌을 덮어쓰는 경우, 작품명 숫자를 회차로 해석하는 경우, RSS 요약이 본문의 추가 회차를 가리는 경우, 중첩 게시물 HTML과 쿼리의 더하기 기호 변형을 검증에 추가했다. 새 회귀 테스트 6개의 실패를 확인한 뒤 수정했다. 보류한 중요한 항목은 없다.

## 측정 결과

로컬 Linux x64 NativeAOT에서 실제 사이트를 조회한 단일 실행 결과다. 네트워크 지연이 포함되며 완전한 전체 검색 시간의 보장 수치가 아니다.

| 요청 | 경과 시간 | 첫 진행 | 첫 발견 | 결과 |
| --- | --- | --- | --- | --- |
| 흉란영애 | 9.77초 | 0.018초 | 2.90초 | 1화부터 5화, 완전 조사 성공 |
| Working, 30초 제한 | 30.02초 | 0.012초 | 7.71초 | 본편 14개와 별도 특별편 1개 보존, 불완전 |
| Working, 12초 후 SIGINT | 12.02초 | 즉시 | 제한 전 발견 | 목록 5개 보존, 종료 코드 130 |

흉란영애의 동일 전체 조사에서 Blogspot 요청은 22개에서 8개로 줄었다. 공개 피드의 페이지 크기를 50에서 서버가 지원하는 150으로 늘리고 전체 수와 순회 검증은 유지했다.

Working은 2015년과 2016년의 삭제된 글, 잘못된 Blogspot 주소와 제한된 목록이 남아 있다. 이 출처들을 성공으로 바꾸거나 모든 자막을 찾았다고 표시하지 않는다. 전체 timeout, 출처별 미완료와 부분 결과가 동작하는지 확인했다.

전체 테스트 95개 통과. 경고를 오류로 처리한 NativeAOT CLI 및 smoke 게시 성공. 직접 다운로드, 합본, 미발견, 전체 검색과 취소 부분 결과 smoke를 실행했다. 실제 측정 JSON과 진행 로그는 Git에서 제외되는 `artifacts/performance-fix/`에 보관한다.
