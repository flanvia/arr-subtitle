# v0.1.1

## 변경

- 같은 제작자 블로그의 여러 작품 탐색을 공유하고 독립 출처를 최대 4개씩 조사한다.
- 진행 상황과 발견 회차를 즉시 stderr에 출력한다. JSON stdout은 최종 문서 하나만 유지한다.
- 전체 검색 기본 제한은 60초이며 `--timeout`으로 변경한다. 취소와 timeout에서도 부분 결과를 보존한다.
- 작품별 티스토리 카테고리, 내장 게시물과 합본 ZIP 회차를 확인한다.
- 한국어 및 일본어 JSON을 UTF-8 문자로 출력한다.
- 누적 합본은 caption, 게시물과 개별 첨부의 일치 근거로 시즌 회차에 연결한다. 원본 번호와 근거를 보존한다.
- 제작자별 회차 변환을 격리하고 충돌 및 근거 없는 변환을 거부한다.
- Linux 바이너리에 OpenSSL 3.5.9를 정적으로 포함한다. OpenSSL 4 환경에서 별도 libssl 설치나 환경 변수 없이 실행한다.

## 검증 범위

로컬 테스트 118개와 Linux x64 NativeAOT, 실제 합본 검색 및 다운로드, OpenSSL 4 Fedora 컨테이너의 HTTPS를 확인했다. 6개 대상 CI가 모두 성공한 뒤 Release를 공개한다.

막힌 출처와 삭제된 게시물은 여전히 불완전 결과로 반환한다. 모든 작품의 전 회차 탐색 성공을 보장하지 않는다. Linux에는 시스템 CA, glibc와 ICU가 필요하며 musl은 지원 대상이 아니다. 정적으로 포함한 OpenSSL의 보안 갱신은 새 바이너리 재배포로 수행한다.
