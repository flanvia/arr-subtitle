# 한글 JSON 및 특정 작품 검색 보완

## 확인한 원인

- 기본 System.Text.Json encoder가 한국어와 일본어를 유니코드 escape로 직렬화했다.
- 정식 작품명을 쓰지 않는 제작자 카테고리를 놓쳐 블로그 전체를 조사했다.
- 네이버 공개 검색 이후 관련 없는 최신 글 목록까지 순회했다.
- 일부 목록은 다른 페이지 번호에서도 같은 글을 반복 반환했다.
- 전체 자막 글의 합본을 최신 회차 하나로만 처리했다.
- 티스토리 첨부 표시의 파일 크기 문자열이 파일명 판정을 방해했다.
- 여러 작품 검색에서 메타데이터와 한 출처가 전체 시간을 소모했다.

## 수정

JSON은 source-generated context와 UnicodeRanges.All encoder를 사용한다. HTML 위험 문자와 제어문자의 JSON escape는 유지한다. CLI, manifest, 설정과 NativeAOT smoke에 적용했다.

티스토리는 caption 게시물의 공개 JSON `categoryLabel`에서 작품별 범위를 확인한다. 범용 자막 카테고리는 작품 전용으로 간주하지 않는다. 짧은 영문 첨부 별칭은 해당 제작자 및 해당 카테고리의 seed 증거로만 사용한다. 다른 작품이나 시즌의 파일을 허용하는 전역 별칭으로 만들지 않는다.

전체 및 합본 게시물은 ZIP 멤버를 검사하고 실제 회차를 나열한다. HTML 오류 응답, 위험한 경로, 작품 및 시즌 충돌은 거부한다. 복수 시즌 합본의 누적 번호를 현재 시즌 회차로 추측하지 않는다. 네이버 전체 검색은 무관한 최신 글 순회를 하지 않으며, 완전성을 확인할 수 없으면 불완전으로 반환한다.

출처별 시간 예산과 최대 4개 동시 실행을 유지하고, 확인한 작품 카테고리를 먼저 시작한다. Anissia 검색 응답의 정보를 재사용하되 원제가 없을 때는 상세를 조회한다.

## 검증

- 전체 테스트 107개 통과
- 경고를 오류로 취급한 .NET 빌드 및 Linux x64 NativeAOT 게시
- JSON에 실제 한국어와 일본어 포함, 필요한 HTML escape 유지
- 직접 다운로드, 합본, 미발견, 검색, 취소 부분 결과 NativeAOT smoke
- 잘못된 ZIP 작품 및 디렉터리 시즌, HTML 반환 합본, 범용 카테고리, 내장 게시물 카테고리, 한국어 시즌 및 누적 회차 검증

외부 출처의 삭제 및 접근 제한은 수정으로 복구되지 않는다. 검색 결과가 있어도 허용 출처 일부가 막히면 종료 코드 1과 출처별 미완료를 반환한다. 전체 timeout과 개별 출처 미완료는 구분해서 보고한다.

## 실제 재검증

로컬 Linux x64 NativeAOT의 단일 실행 결과이며 외부 사이트 지연이 포함된다.

| 검색 | 시간 | 발견한 회차 | 전체 timeout |
| --- | --- | --- | --- |
| 여친 | 56.52초 | 여러 작품의 부분 목록, 그녀도 여친 2기 1화부터 12화 포함 | 없음 |
| 여친, 빌리겠습니다 | 36.26초 | 1기 1화부터 12화 | 없음 |
| 수염을 깎다 | 22.35초 | 1화부터 13화 | 없음 |

모두 한국어가 escape되지 않은 JSON을 반환했다. 세 검색 모두 아직 출처 일부가 불완전하므로 종료 코드 1이다. 특히 여친, 빌리겠습니다 2기의 합본은 1화부터 24화의 누적 번호이고 caption은 시즌 회차이므로, 이를 2기 1화부터 24화라고 잘못 등록하지 않는다. 3기 네이버 첨부와 접근 제한 출처도 완전한 목록을 보장하지 못한다. 성공 종료를 강제로 만들지 않았다.

넓은 여친 검색도 수십 초 걸릴 수 있다. 여러 작품과 출처를 조사하는 비용이며 이번 수정이 즉시 전체 수집을 보장하는 것은 아니다. 진행 표시와 부분 결과, 구체적인 미완료 원인을 함께 사용한다. 원시 결과는 Git에서 제외되는 `artifacts/search-timeouts/`에 있다.

사용자가 커밋, push와 Release를 승인하여 이전 검색 성능 및 누적 합본 수정과 함께 `v0.1.1` 배포를 준비한다. OpenSSL 4 환경의 TLS 실행 문제는 정적 연결로 보완했으며 별도 검증은 `cumulative-and-tls.md`에 기록한다.
