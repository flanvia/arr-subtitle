# 자막 전체 검색

`arr-subtitle search "흉란영애"`는 관련 Anissia 작품들을 찾고 각 작품의 현재 자막 링크와 제작자 및 등록 블로그의 과거 게시물을 회차별로 나열한다. 하나의 작품을 임의로 선택하지 않는다. 자막 파일을 사용자 폴더에 저장하지 않는다. 전체 자막이나 합본으로 표시된 글은 ZIP을 받아 멤버 목록에서 실제 포함 회차를 확인할 수 있다.

## 탐색 방식

Anissia 자동완성만 반환하는 방식은 과거 회차를 찾지 못하므로 사용하지 않는다. 작품 목록의 모든 페이지를 조회하고, 각 작품의 상세 및 caption을 확인한다. 제작자 블로그와 등록된 전역 블로그는 다운로드 fallback과 달리 모두 조사한다. 첫 자막을 찾았다고 나머지 회차나 제작자 탐색을 중단하지 않는다.

Blogspot은 전체 공개 피드를 페이지 순회하고 작품 근거로 필터링한다. 최신 게시물의 라벨이 과거 모든 게시물에도 있다는 가정을 하지 않는다. 전체 수와 실제 조회 수, 다음 페이지를 검증한다. 다른 플랫폼은 기존 HTTP 탐색을 재사용하며 완전성을 확인하지 못하면 불완전 탐색으로 표시한다.

결과는 작품, 회차, 제작자 또는 블로그, 게시물, 첨부파일 후보를 포함한다. 동일 회차의 다른 제작자는 유지하고 동일 게시물과 첨부는 중복 제거한다. 게시물에 명시된 회차 범위는 펼쳐서 표시한다. 첨부 후보의 존재는 실제 자막 본문 및 영상 싱크 검증을 뜻하지 않는다.

티스토리의 caption 게시물에서 공개된 `categoryLabel`을 확인할 수 있으면 그 작품 카테고리를 먼저 조사한다. 제작자가 정식 작품명이 아닌 글 제목을 사용해도 해당 카테고리의 글을 찾는다. 다른 카테고리의 자막을 제목 유사도만으로 합치지 않는다.

## 누락과 실패

발견한 최대 본편 회차까지 정수 회차의 빈 번호를 별도로 보고한다. 미방영 화수나 최종 전체 화수를 추측하지 않는다. 외부 메타데이터에 없는 끝 회차를 완전 수집했다고 주장하지 않는다.

작품 검색, 게시물 목록 또는 본문을 끝까지 확인하지 못했거나 회차 번호 및 첨부가 모호하거나 중간 회차가 비면 발견 결과를 유지하면서 종료 코드 1을 반환한다. 정상 조사했지만 결과가 없어도 1이다. 취소는 130이다. JSON 출력은 부분 결과와 출처별 실패를 보존한다.

## 응답 시간과 진행 표시

전체 검색은 기본 60초로 제한한다. 더 긴 조사가 필요하면 `search 'Working' --timeout 120`처럼 1초부터 600초까지 지정할 수 있다. 제한 시간에 도달하면 조사 중인 작품에서 이미 발견한 회차도 반환한다. 시간 제한은 누락된 회차를 정상 수집한 것으로 바꾸지 않는다.

출처가 많은 검색은 전체 시간을 출처 묶음에 나눠 한 블로그가 다른 블로그의 실행 기회를 모두 소모하지 않게 한다. 출처당 최대 20초를 사용하고, 확인한 티스토리 작품 카테고리 조사는 먼저 시작해 최대 40초를 사용한다. 예산을 넘긴 출처는 미완료로 남긴다. Anissia 작품 목록에 이미 포함된 작품 정보는 재사용하고 원제가 빠진 경우만 상세 조회한다.

작품 조사, 블로그 요청과 회차 발견을 stderr로 즉시 표시한다. `--json` 사용 시에도 stdout은 최종 JSON 문서 하나이며 진행 메시지는 stderr다.

같은 제작자 블로그는 작품별로 반복 순회하지 않고 한 번 조사해 관련 작품에 배분한다. 서로 다른 블로그는 최대 4개를 동시에 조사한다. 같은 호스트의 요청 간격 1초와 외부 주소 검증은 유지한다. 페이지 URL의 중복과 관련 없는 달력 및 다른 카테고리 페이지 확장은 제한한다. 서버 검색 결과에 본문이 포함된 경우 별도 본문 요청을 반복하지 않는다.

네이버의 전체 검색에서 관련 없는 최신 글 목록을 끝없이 순회하지 않는다. 공개 검색 및 확인 가능한 작품 목록을 처리하되 완전성을 확인하지 못하면 미완료로 남긴다. 목록 URL이 다르더라도 같은 게시물 집합을 반복 반환하면 순회를 중단한다.

JSON 출력과 manifest 및 설정은 한국어와 일본어를 UTF-8 문자로 보존한다. 제어문자, 따옴표와 HTML 위험 문자의 필요한 JSON escape는 유지한다.

합본에 누적 번호가 있으면 caption의 시즌 회차와 그 게시물 제목 및 단일 회차 첨부의 번호가 일치하는지 확인해 출처별 오프셋을 만든다. 예를 들어 caption 12화와 게시물 및 개별 첨부 24화가 대응하면, 합본 13화부터 24화는 시즌 1화부터 12화다. 결과에는 `sourceEpisode`와 `numberingEvidence`를 보존한다. 합본의 최댓값만 보고 추측하지 않으며 대응 근거가 없거나 충돌하면 `numbering-ambiguous`다.

오래된 작품의 삭제 게시물, 잘못된 주소나 공개 목록 제한 때문에 모든 출처를 완전히 조사하지 못할 수 있다. 진행 표시가 나온다고 전체 수집 완료를 뜻하지 않으며 최종 `complete`와 출처별 결과를 확인해야 한다.
